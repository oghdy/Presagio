# 학습 노트 (docs/learning) 읽는 법

> 이 폴더는 **이 프로젝트를 만든 사람 본인**을 위한 공부 자료다.
> 목표는 하나: 면접에서 "왜 이렇게 만들었나"를 자기 말로 설명할 수 있게 되는 것.

## 무엇이 들어있나

| 파일 | 내용 | 언제 읽나 |
| --- | --- | --- |
| `glossary.md` | 이 프로젝트에 나오는 용어를 쉬운 말로 풀이. 단계가 진행되면 계속 늘어난다. | 모르는 단어가 나올 때마다 |
| `how-this-company-works.md` | 에이전트 회사가 어떻게 돌아가는지, 네가 뭘 하면 되는지 | 지금 바로 |
| `stage-N-*.md` | 단계가 끝날 때마다 PM이 쓰는 정리. 무엇을 왜 만들었나, 실패한 것, 면접 예상 질문 | 단계 종료마다 |

## 공부하는 순서 (추천)

1. **PR이 올 때마다:** PR 본문의 "이 PR을 3문장으로"를 읽는다. 이해 안 되면 PM 세션에 "더 쉽게 설명해줘"라고 한다. 이해될 때까지 머지하지 않는다.
2. **머지하기 전에:** PM의 수락 메시지에 있는 "네가 물어볼 만한 질문"을 실제로 PM에게 물어본다. 답을 듣고 자기 말로 한 번 되뇌어 본다.
3. **단계가 끝나면:** `stage-N-*.md`를 읽고, 끝에 있는 면접 예상 질문에 **문서를 안 보고** 답해 본다. 막히는 질문은 PM에게 다시 설명을 요청한다.
4. **용어가 쌓이면:** `glossary.md`를 처음부터 훑는다. 각 용어를 한 문장으로 설명할 수 있으면 통과.

## 이 문서들의 글쓰기 규칙 (PM과 Scribe가 지킨다)

- 전문 용어는 그 자리에서 괄호로 풀어 쓴다.
- "무엇을 했다"만 쓰지 않는다. 반드시 "왜"와 "다른 선택지는 뭐였고 왜 안 골랐나"를 쓴다.
- 숫자는 표로, 코드는 코드 블록으로.
- 문서 끝에 면접 예상 질문 2~3개와 모범 답을 붙인다.
