# 실험 기록 (Experiments)

> 단계 2부터 ML Engineer가 쓴다. **실패한 실험도 반드시 기록한다.**
> 좋은 결과만 남기면 나중에 같은 실패를 반복하고, 면접에서 "왜 이 모델이냐"에 답할 수 없다.

## 기록 규칙

- 번호: E-001부터. 한 실험 = 한 가설(설계 `docs/design/modeling-v1.md` 7-1의 `H-NN`).
- 모든 실험은 walk-forward 평가 결과만 적는다. 무작위 분할 결과는 기록하지 않는다(의미가 없다).
- 항상 같은 경기 집합에 대해 기준선(홈팀 승 / 시즌 승률 / Elo)과 나란히 적는다. 실험 간 비교는 `presagio backtest compare`(공통 경기 집합 + 짝 부트스트랩)로 낸다.
- 재현에 필요한 것: 코드 커밋 해시, 피처 버전, 학습 기간, 시드, 하이퍼파라미터, 실행 명령 한 줄.
- **사전 등록:** 가설·비교 대상·사전 판정 기준·경기 집합·실행 명령을 결과를 보기 **전에** 이 문서에 적고 main에 머지한다(상태 `등록(미실행)`). 결과는 그 뒤 다른 PR에서 채운다. 판정 기준 문장은 결과를 본 뒤 바꾸지 않는다(바꿔야 하면 새 번호로 다시 등록, 설계 7-1).
- **표본 부족:** 판정에 쓰는 비교의 n < 100이면 숫자는 "참고(표본 부족)"로 적고 판정을 보류한다(설계 4-6).
- **보고 시즌 1회:** 2024-25 판정 비교는 가설마다 사전 등록된 비교 **한 번**만 돌린다. 다시 돌려 고르지 않는다. 추가로 돌린 것은 `exploratory`로 표시하고 선택 근거로 쓰지 않는다(설계 6-4).
- **보류 시즌(2025-26):** 열지 않는다. 연 경우에는 해제 사유와 몇 번째 해제인지를 적는다(설계 6-3).

## E-001 H-01: 문헌 출발 상수의 Elo(B2) vs 항상 홈(B0)·시즌 승률(B1)
- **상태:** 실행됨 (2026-11-10 18:07~18:11 KST, 코드 `847a27c`). 판정: 세 항목 모두 충족
- **가설 번호:** H-01
- **날짜:** 등록 2026-11-10 / 실행 —
- **가설:** 문헌 출발 상수의 Elo(B2)는 항상 홈(B0)·시즌 승률(B1)보다 확률 품질이 좋다
- **비교 대상:** B2 vs B0, B1
- **지표:** log loss, Brier, 정확도
- **사전 판정 기준:** `LL_B2 ≤ LL_B0 − 0.02` **그리고** `Brier_B2 ≤ Brier_B0 − 0.005` **그리고** `acc_B2 ≥ acc_B1`. 하나라도 어기면 구현을 먼저 의심(감사)
  - 판정 방법(등록 시 정함): 세 항목을 각각 `판정: 충족 / 미충족`으로 적는다. 판정 구간은 **2024-25 전체**(`2024-25 | all` 행). 2023-24 후반(2024-01-01 이후 = 보고 대상, `2023-24 | all` 행)은 참고. `LL_B2 − LL_B0`·`Brier_B2 − Brier_B0`는 `--reference B0` 출력의 B2 행 `dLL`·`dBrier`(점추정과 90% 구간을 함께 적는다), `acc_B2 − acc_B1`은 `--reference B1` 출력의 B2 행 `dAccuracy`. 하나라도 미충족이면 승패를 선언하지 않고 "구현 의심 → 감사 요청"으로 적는다.
  - **판정(PR B, 실행 뒤 추가. 위 두 줄은 등록 문장 그대로다).** 판정 구간 `2024-25 | all`, n 1,320:
    1. `LL_B2 ≤ LL_B0 − 0.02` — `LL_B2 − LL_B0` = -0.0603 [-0.0788, -0.0435] → **판정: 충족** (구간 상한도 −0.02 아래).
    2. `Brier_B2 ≤ Brier_B0 − 0.005` — `Brier_B2 − Brier_B0` = -0.0284 [-0.0363, -0.0213] → **판정: 충족** (구간 상한도 −0.005 아래).

- **결론:**
  1. **채택 조건 충족.** 2023-24에서만 고른 설정(K=20, HCA=50, carry=0.9)이 2024-25 전체에서 출발값보다 log loss가 낮다(0.6183 vs 0.6304, 차이 -0.0122 [-0.0182, -0.0056]). 구간 상한(-0.0056)도 채택 기준(−0.005) 아래지만 기준에 거의 닿아 있다. "기준을 넘는 개선"은 맞고 "기준을 크게 넘는다"고는 말할 수 없다. Brier -0.0052 [-0.0079, -0.0023], 정확도 0.656 vs 0.640(+0.016, 참고), ECE 0.0778 → 0.0335.
  2. **선택 시즌의 개선이 선택에 쓰지 않은 시즌에서도 유지됐다.** 선택 창에서 K·HCA 최적 칸과 출발 칸의 log loss 차는 -0.0170이었고, 2024-25에서 채택 설정과 출발값의 차는 -0.0122다. 크기는 줄었지만 방향이 같고 구간이 0을 제외한다. 선택 창에 과적합된 결과만으로는 설명되지 않는다(두 수는 carry와 창이 달라 크기를 직접 견줄 수는 없다).
  3. **바뀐 것은 사실상 HCA 하나다.** K는 출발값 20이 그대로 최적이었고 K 방향은 평평하다(HCA 50 줄에서 K 15·20·25가 0.6203·0.6196·0.6207). HCA는 다섯 K 모두에서 125 → 100 → 75 → 50 순서로 log loss가 내려간다. carry 0.9는 선택 창에서 0.75보다 0.0005 낮을 뿐이다(0.6133 vs 0.6138). 규칙(최소 log loss, 동률 아님)대로 골랐지만 carry에 관해서는 "0.9가 낫다"가 아니라 "차이를 보지 못했다"가 정직한 표현이다.
  4. **왜 HCA 50인가.** 홈 어드밴티지 100점은 실력이 같은 두 팀에서 홈 승률 0.640, 50점은 0.571을 뜻한다(설계 5-2 기대 승률 식에 레이팅 차 0을 넣은 값). 실제 홈 승률은 2023-24 후반 0.533, 2024-25 0.545다. 설계 5-2에 적어 둔 우리 데이터의 정규시즌 평균 홈 점수 차(+2.15 / +1.63)도 538의 약 3.5점보다 작았다. ECE가 0.0778에서 0.0335로 내려간 것이 같은 이야기다. 개선의 정체는 "팀 실력을 더 잘 재는 레이팅"보다 "홈 쪽으로 치우친 확률을 바로잡은 것"에 가깝다.
  5. **한계.** (가) 최적 칸이 격자 경계에 있다. HCA 50은 격자의 최솟값이고 carry 0.9는 최댓값이다. 진짜 최적은 등록된 격자 밖(더 낮은 HCA)에 있을 수 있다. 격자를 넓히는 것은 새 실험이다.
